순기구학(FK) 계산값 · 단위: cm(가정) · 관절 제어·그리퍼·초기화는 우측 3D 화면 위 플로팅 컨트롤러(C1~C3)에서 조작하세요.

§2 수행활동 · PERFORMANCE TASK

어느 미션을 보고 있든 언제든 사용 가능합니다. 로봇이 실제로 도달 가능한 범위 안에서만 새 위치를 고릅니다.

학습목표 관절좌표계 이해 및 순기구학 기반 자세 제어
제시된 목표 각도로 3D 화면 위 플로팅 컨트롤러(C1)의 J1~J6 게이지를 조작해 로봇 자세를 재현하세요. (허용오차 ±5°)

학습목표 엔드이펙터(그리퍼) 제어 및 작업경로 계획
앰버색 테두리 작업물을 그리퍼로 파지해 청록색 원(목표 구역)까지 옮기세요. 그리퍼를 물체 근처에서 닫으면 파지되고, 목표 구역 위에서 열면 배치가 완료됩니다.

상태대기 중
§3 수행 기록 · LOG

학번이 포함된 파일명으로 저장됩니다. 학급 제출함(구글 클래스룸 등)에 올려주세요.

§4 동작 프로그래밍 · MOTION PROGRAM

산업용 로봇의 교시-재현(Teach & Playback) 방식을 연습하는 코드입니다.

MoveJ / Gripper / Wait는 이 시뮬레이터가 만든 교육용 형식입니다.

재생 준비 초기화: 로봇 자세·그리퍼·픽앤플레이스 물체 위치를 시작 상태로 되돌립니다 (기록된 코드는 유지).

§5 코드 입력 실행 · CODE INPUT

교육용 단순 문법, 두산 DRL 스타일, UR(URScript) 스타일을 모두 인식합니다. 한 줄에 한 명령씩 입력하세요. MoveJ / Gripper / Wait · movej(posj) / set_digital_output / wait · movej([q]) / set_digital_out / sleep

§6 역기구학 위치 제어 · IK (실험적)

목표 좌표(X, Y, Z)를 입력하면 J1~J3을 계산해 그 위치로 이동합니다. 손목(J4~J6)은 0°로 고정하는 위치 전용 IK이며, 방향(자세)까지 함께 계산하는 완전한 6DOF IK는 아닙니다.

🟢 좌표 측정 구체 (PROBE)

3D 화면 속 초록 구체를 드래그하면 그 지점의 좌표가 항상 표시됩니다. 화면을 회전하면서 여러 각도에서 옮기면 공중의 임의 지점도 지정할 수 있습니다.
